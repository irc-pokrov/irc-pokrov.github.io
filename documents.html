Матеріали з питань захисту прав дитини:  таблиця матеріалів до кампанії "Дитина і право: безпека у цифровому та реальному світі":
1. Діти мають право самостійно звертатися по правничу допомогу. 
2. Як дорослим виявляти і протидіяти насильству щодо дітей.
3. Кібербулінг: як розпізнати, що робити та куди звертатися, щоб убезпечити дитину.
4. Булінг: ознаки та куди звертатися по допомогу.
5. Спільна дитина — спільна відповідальність: як врегулювати суперечки. 
6. Фізичні покарання: вплив на дитину та відповідальність для дорослих.
7. Юрист для дитини: коли це потрібно та як отримати допомогу безоплатно.

Комплексна психолого-педагогічна оцінка розвитку дитини проводиться за попереднім записом.

Звертаємо Вашу увагу про можливість подання документів для проведення комплексної психолого-педагогічної оцінки розвитку дитини через автоматизовану систему роботи КУ "Покровський ІРЦ": pеєстрація.

 Документи, які потрібні для комплексної оцінки розвитку дитини:

  • Згода  батьків (одного з батьків) або законних представників на обробку персональних даних їх неповнолітньої дитини ( скачати форму у форматі word або pdf ) 
  • Заява щодо проведення комплексної психолого-педагогічної оцінки розвитку дитини ( скачати форму у форматі word та pdf ) 
  • Характеристика (завірена)
  • Форма первинної облікової документації № 112/о "Історія розвитку дитини" ( Медична карта Ф-112/о )
  • Копія свідоцтва про народження дитини
  • Паспорт для підтвердження особи батьків
  • Висновок в 2-х екземплярах
  • Зошити з рідної мови, математики
